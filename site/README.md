# Holocron documentation site

Static Astro with the published `zuedocs@0.1.26` shell: native navigation, table of contents, code/page copy, theme controls, Pagefind production search and sitemap. The local layout supplies Holocron branding, canonical/social metadata, self-hosted fonts and a skip link.

## Develop and check

Use Node 24 and Bun **1.4.0** from the full repository checkout:

```sh
bun install --cwd site --frozen-lockfile
bun run --cwd site dev
bun run --cwd site check
git diff --check
```

The required site gate is **Astro check only**. Do not add a local Astro build to that gate. Source/docs scans and affected package checks can run independently. The production build happens at deployment; `build` remains a separate command. Optional `validate` is a build-dependent production link/search/asset validator, not the required local gate.

Pagefind search is generated by the production build; development mode provides its native preview hint. Test production search against the deployed site or an existing production artifact. Preview an existing build with `bun run --cwd site preview -- --host 127.0.0.1 --port 4321`.

## Canonical content

- `../docs/*.md` is the sole guide source, used directly by Astro and shipped in the CLI release bundle. Frontmatter owns title, description, order and category.
- Keep `guide.md#heading` links portable for repository/package readers. `scripts/docs-links.mjs` maps them to website routes.
- `/docs/<slug>.md` serves the original source bytes for Markdown/page-copy actions.
- `src/data/docs.ts` owns site metadata and categories. The landing page links to canonical tasks.
- New guides must be added to `../scripts/package-smoke.mjs`'s explicit allowlist and the expected guide count in `scripts/validate-site.mjs`.

Static content needs no credentials. No runtime directory is loaded. Keep private configs, actual plugin IDs, tokens and CLI archives outside source/public assets. Font notices for DM Sans and Instrument Serif stay in `public/font-notices.txt`.

## Hosting reference

| Setting | Value |
| --- | --- |
| Root Directory | `site` |
| Include source files outside Root Directory | Enabled, for `../docs` and shared API source |
| Framework / Node | Astro / 24.x |
| Install Command | `bunx bun@1.4.0 install --frozen-lockfile` |
| Build Command | `bunx bun@1.4.0 run build` |
| Output Directory | `dist` |
| Domain | `holocron.ashray.xyz` |
| Static environment variables | None |

`vercel.json` owns deployment commands and response headers. Keep the explicit Bun build-tool pin: `packageManager` alone does not select Vercel's build-container Bun. Do not set `bunVersion`; the secret API uses the Node runtime.

`public/install.sh` is copied to `/install.sh`, pinned to **0.3.2**, and downloads the public GitHub release anonymously. `public/setup.sh` becomes `/setup.sh`; it installs missing user-local Node 24.21.0 from fixed official SHA-256 pins, then runs the public installer/setup. Earlier published tags/assets stay immutable. Do not duplicate release bundles under `public/`. See [release maintenance](../docs/operations.md#publish-the-cli-release-and-installer).

## Separate secret API

The deployed `/api/secrets` Node function uses shared root relay code and three private provider variables, documented in [relay operator reference](../docs/secret-operations.md#relay-operator-reference). Static docs stay independent. The relay holds public metadata/credential hashes/ciphertext, never entered key plaintext or endpoint private keys. Disable external payload/header capture.

Keep `rewriteRelativeImportExtensions: true` in TypeScript configuration so Vercel's emitted shared `.ts` imports become `.js`. Packaging changes require isolated compiled-function checks; source typechecking alone does not prove emission loads.

A production synthetic ciphertext/consume/replay/revoke probe passed. Actual intended receiver/native GUI acceptance remains pending. Site changes do not configure accounts, pair endpoints, restart services or deploy anything.

The known site dependency audit baseline **GHSA-ch52-4w7c-c8xp** (`http-cache-semantics` through Astro) remains unsuppressed. Retain `bun audit --cwd site --audit-level=low` for the operator's dependency gate; it is separate from Astro diagnostics. The static docs/uncached relay add no authenticated shared HTTP cache or remote image reuse path.
